# Smart BMS – Battery Health Monitoring

Machine Learning based Smart Battery Management System using Streamlit.

## Features
- SOH prediction
- Remaining life estimation
- Safety alerts
- Interactive dashboard

## Technologies
- Python
- Scikit-learn
- Streamlit
- NumPy
- Matplotlib

## Run Project

streamlit run bms_app.py

## Models Used
- Random Forest Regressor
- Feature Scaling
